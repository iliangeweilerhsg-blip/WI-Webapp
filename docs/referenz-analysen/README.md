# Referenz-Analysen

Hier landen die Recherche-Ergebnisse zu den Referenz-Apps, eine Datei pro App (`goodnotes.md`, `quizlet.md`, `studysmarter.md`). Die Quellen in der Reihenfolge aus `../FEATURE-KATALOG.md` §1: öffentliche Infos, Open Source, eigene Beobachtung, und nur für Restfragen der REA-Skill.

Aufbau pro Funktion:
- **Funktion** und Moment (M1–M13) aus `../STUDIENALLTAG.md`
- **Gesehen:** was die statische Analyse belegt (Datei/Modul, kurz in eigenen Worten)
- **Abgeleitet:** was daraus folgt
- **Unklar:** was offen bleibt
- **Unsere Umsetzung:** wie wir es selbst bauen und wo es besser wird

Kein dekompilierter fremder Code, nur Beschreibungen in eigenen Worten.
