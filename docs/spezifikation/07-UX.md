# 07 · UX & Oberfläche

## 1. Gestaltungsziele

1. **In der Vorlesung unsichtbar** – die App tritt zurück, Folie und Schrift stehen im Vordergrund (LP1, LP5).
2. **Danach ein ruhiger Begleiter** – *ein* Vorschlag statt vieler Listen (LP7, LP9).
3. **Alles führt zur Quelle** – jede Aussage ist anklickbar und führt zu Folie, Audio oder Notiz (LP8).

- Zurück/Vor mit `⌘[` `⌘]`. Jeder Bildschirm hat eine URL (Deep Links für Quellen-Chips).

## 3. Bildschirme Mac

### 3.1 Heute (Startbildschirm)
```
┌───────────────────────────────────────────────────────────────────┐
│ Dienstag, 4. November                                              │
│                                                                   │
│ ┌─ Gleich ─────────────────────────────────────────────────────┐  │
│ │ Datenbanksysteme · VL 7 · 08:15 · H 012          [  Start  ] │  │  ← ab 15 min vorher groß
│ │ Folien ✓ · Übung 4 ✓                                          │  │
│ └───────────────────────────────────────────────────────────────┘  │
│ ┌─ Jetzt sinnvoll ──────────────────────────────────────────────┐ │
│ │ Wiederholung · ≈ 12 min                          [ Los ]       │ │
│ │ etwas anderes ›                                                │ │
│ └───────────────────────────────────────────────────────────────┘ │
│ Heute   08:15 DBS VL 7 · 10:15 Statistik · 13:00 Nacharbeitung DBS │
│         (15 min) · 16:00 Übung · Lernzeit gesamt ≈ 55 min          │
│ Sessions  DBS VL 6 · Nacharbeitung bereit ≈ 15 min                 │
│ Fächer   DBS ▮▮▮▮▮▯▯ 62 %   Statistik ▮▮▮▯▯▯▯ 41 % (wenig Daten)   │
└───────────────────────────────────────────────────────────────────┘
```
- Oben je nach Tageszeit: **Tagesbriefing** (morgens) bzw. **Tagesabschluss** (abends) als zusammenklappbare Karte.
- Keine Benachrichtigungen, keine Badges außer der neutralen Inbox-Zahl.

### 3.2 Modul (Fachübersicht)
Kopf: Name, Prüfung (Datum, Art), Readiness (heute / am Klausurtag). Darunter:
- **Tabs:** *Vorlesungen*, *Übungen*, *Konzepte*, *Altklausuren*.
- **Vorlesungen:** Liste mit Nummer, Datum, Status (aufgenommen · verarbeitet · nachgearbeitet). Ablageziel für Folien-PDFs.
- **Konzepte:** sortierbar nach Vorlesung, Schwäche oder Wichtigkeit.

### 3.3 Live-Dashboard (laufende Session)
```
┌──────────────────────────────────┬──────────────────┬───────────────────┐
│                                  │ Blatt 4 · 2b      │                   │
│         FOLIE 23 / 48            │ „Bringen Sie die  │   Notizseite      │
│                                  │  Relation in 3NF" │   (live vom iPad) │
│                                  │ passt: Definition │                   │
│                                  │ der 3NF           │                   │
│ ‹ Folienleiste (einblendbar) ›   │                  │                   │
├──────────────────────────────────┴──────────────────┴───────────────────┤
│ ● 00:42:13   ❓ 2  ⚠️ 1  🔗 0   ·  iPad ●   ·  ❚❚  ■           ⌘K          │
└─────────────────────────────────────────────────────────────────────────┘
```
- **Dunkles, gedimmtes Erscheinungsbild** als Standard in der Session (Hörsaal).
- **Keine Animationen** außer dem Blättern (≤ 150 ms).
- Die Übungsspalte wechselt **nur** mit der Folie. Ohne Treffer ist sie leer, mit dem dezenten Text „keine Aufgabe zu dieser Folie".
- Folienloser Modus: In der Folienspalte steht ruhig „Folien kommen später – einfach mitschreiben". Dorthin können PDFs auch während der Session gezogen werden.
- Stopp-Hinweis (F-SES-03) erscheint als Textzeile in der Statusleiste, nicht als Overlay.

### 3.4 Rückblick einer Vorlesung
```
┌────────┬──────────────────────────────────┬───────────────────────┐
│ Folien │  FOLIE 14                         │ Meine Notizen (2)     │
│ ▢ 12   │                                   │ [Seite 3]  ❓ 08:41    │
│ ▣ 14   │                                   │                       │
│ ▢ 15   ├──────────────────────────────────┤ Fotos (1)             │
│  …     │ Transkript zu Folie 14            │                       │
│        │ 08:40 „Die dritte Normalform…" ▶  │ Aufgaben: Blatt 4 2b  │
│        │ 08:41 „…und das ist klausur-      │                       │
│        │        relevant." ⚠️              │ Konzepte: 3NF, FA     │
├────────┴──────────────────────────────────┴───────────────────────┤
│ ▶ ❚❚  08:40:12 ━━━━━━●━━━━━━━━━━━━━━━━━━━  1,25×  ⟲15 ⟳15  Wiedergabe│
└────────────────────────────────────────────────────────────────────┘
```
- Zeitleiste über dem Player mit Folien-Segmenten (F-NAC-03 zum Korrigieren: Grenzen ziehen), Markern und Strich-Dichte.
- „Wiedergabe" schaltet den Notiz-Wiedergabemodus ein (F-NAC-04).

### 3.5 Geführte Nacharbeitung
Vollflächige, fokussierte Ansicht mit Fortschritt *„Schritt 2 von 6 · ≈ 9 min übrig"*. Pro Schritt ein einziges Element im Fokus. Unten immer „Pause" (setzt später genau dort fort).
- **Konzeptvorschläge als Stapel:**
  - **Inhalt der Karte:** Name, Ein-Satz-Definition, Belege als kleine Kacheln, Vorschlag „gleich wie *X*?".
  - **Aktionen:** `→` / Wisch rechts = annehmen · `←` / Wisch links = verwerfen · `E` = bearbeiten.

### 3.6 Konzeptansicht
Zweispaltig:
- **Links:** Notiz (Markdown, direkt editierbar). Eigene Abschnitte sind leicht hervorgehoben („deine Worte").
- **Rechts:**
  - Beherrschung mit Band und Verlauf
  - Belege als Kacheln
  - Beziehungen nach Typ
  - Karten (Anzahl je Stufe)
  - Videos
  - „Frag deine Vorlesung" zu diesem Konzept
  - Fächerbrücken-Hinweis

### 3.7 Graph
Vollbild, Filterleiste oben, Seitenleiste rechts bei Auswahl. „Lernpfad" hebt die Voraussetzungskette hervor. Farbskala Beherrschung: kühl/blass (unsicher, niedrig) → kräftig (sicher, hoch). **Kein Rot-Grün** (Farbsehschwäche, LP9).

### 3.8 Lernen
- **Startbereich:** ein Hauptknopf (empfohlene Einheit mit Dauer), darunter Alternativen: *Wiederholung*, *Lernsitzung neue Konzepte*, *Schwächen*, *Probeklausur*, *Feynman*, *Übungsmodus*, *Karten verwalten*.
- **Karte:** zentriert, große Schrift.
  - Aufdecken mit Leertaste, Bewerten mit `1`–`4`.
  - Fortschritt nur als dünne Linie oben.
  - Quellen-Chip unter der Antwort.
  - KI-Bewertung offener Antworten erscheint unter der eigenen Antwort mit vorgewählter Note.
- **Readiness je Fach:** zwei Balken (heute, Klausurtag mit Plan) mit Band und die 5 Hebel als Liste mit „üben".
- **Ende einer Einheit:** zwei Sätze, z. B. „18 Karten · 11 min. Am stärksten verbessert: *Normalisierung*." Danach zurück. Keine Konfetti, keine Serien.

### 3.9 Planer
Wochenansicht (Mo–So, 07–22 Uhr):
- **Termine:** grau, gefüllt.
- **Lernblöcke:** in Modulfarbe, umrandet, mit Kurztitel und Dauer.
- **Interaktion:** Ziehen verschiebt, Kante zieht die Länge, Pin fixiert. Klick zeigt die Begründung und „Jetzt starten".
- **Seitenleiste:** Wochensumme, Fristen (Abgaben, Prüfungen).

### 3.10 Videothek & Player
Raster nach Fach → Konzept, Vorschaubild = erste Folie, Dauer, Stufe (V0/V1/V2).
- **Player:** Kapitel, Geschwindigkeit, Quellen-Chips je Abschnitt.
- **Am Ende:** „3 Prüffragen" (keine automatische Weiterleitung zum nächsten Video).

### 3.11 Inbox
Gruppiert nach Session bzw. Quelle. Jede Zeile hat Typ-Symbol, Kurzbeschreibung, Belege, „annehmen" / „verwerfen". Gruppenaktionen. Filter nach Typ.

### 3.12 Suche (⌘K)
Overlay, mittig, 640 px breit. Ergebnisse gruppiert (Konzepte, Folien, Gesagtes, Notizen, Aufgaben, Karten). Gesagtes mit ▶. Unten Hinweis auf Filter-Präfixe. Eine zweite Zeile „Frag deine Vorlesung: ‚…'" leitet die Frage an F-SUC-02 weiter.

### 3.13 Einstellungen
Bereiche laut F-EIN-01, links Liste, rechts Formular. Jede Option mit einem Satz Erklärung. Keine versteckten Experten-Menüs.

## 4. Bildschirme iPad

### 4.1 Kopplung (einmalig)
„Mac suchen …" → gefundener Mac mit Name → 6-stelliger Code auf beiden Geräten → fertig. Alternativ „QR-Code scannen".

### 4.2 Start
```
┌───────────────────────────────────────────────┐
│ Gleich: DBS · VL 7 · 08:15        [ Start ]   │
│ Jetzt sinnvoll: Wiederholung ≈ 8 min [ Los ]  │
│ Notizbücher  DBS · Statistik · …              │
│                                         Mac ● │
└───────────────────────────────────────────────┘
```

### 4.3 Schreibansicht
```
┌───┬────────────────────────────────────────────────────────┐
│ ✒ │  ‹ Folie 23/48 ›   (Leiste, ausblendbar)               │
│ ▭ │                                                        │
│ ⌫ │                                                        │
│ ◌ │                 Seite / Folie                          │
│ ━ │                                                        │
│ 📷│                                                        │
│───│                                                        │
│ ❓ │                                                        │
│ ⚠️ │                                                        │
│ 🔗 │                                         Seiten ▤  ● Mac│
└───┴────────────────────────────────────────────────────────┘
```
- **Werkzeugleiste** vertikal am Rand (links oder rechts, Händigkeit). Reihenfolge: Stift, Textmarker, Radierer, Lasso, Lineal/Formen, Kamera, Trenner, Marker-Stempel.
- **Farben und Stärken:** Werkzeug antippen, dann erscheint ein Popover direkt am Werkzeug, ohne Vollbild.
- **Marker-Stempel** unten in der Leiste (Daumenbereich), je 48 × 48 pt.
- **Folienleiste oben:** schmal, ausblendbar. Zwei-Finger-Wisch blättert.
- **Kein Statusdialog**, nur der Verbindungspunkt.

### 4.4 Wiederholen (Phase 3)
Wie am Mac, für Einhandbedienung optimiert: Karte oben, Aufdecken durch Tipp, Bewertung durch Wisch (links Nochmal, rechts Gut) oder 4 große Buttons unten.

## 5. Interaktionsregeln (verbindlich)

**In der Vorlesung**
| # | Regel |
|---|---|
| R1 | Zwischen Start und Stopp: **kein modaler Dialog, kein Popup, keine Benachrichtigung, keine KI-Ausgabe.** |
| R2 | Jede Aktion höchstens **ein Tipp**. Tippflächen ≥ 44 × 44 pt (Marker ≥ 48 pt). |
| R3 | Statusänderungen (Sync, Mikrofon) nur als dezente Punkte und Kurztexte. Nie blockierend. |
| R4 | Dunkles, gedimmtes Erscheinungsbild. Keine blinkenden oder pulsierenden Elemente (außer dem Aufnahmepunkt, ruhig, 2 s Takt). |

**KI**
| # | Regel |
|---|---|
| R5 | Die KI **schlägt vor**, ich entscheide. Annehmen und Verwerfen je eine Geste. Verwerfen braucht keine Begründung. |
| R6 | Jede KI-Aussage hat einen **Quellen-Chip** (Symbol + Kurzbezeichnung „F 14", „08:41", „Notiz S. 3"). Ein Klick springt hin. |
| R7 | Unsicherheit wird gezeigt („wenig Daten", Band), nie versteckt. |
| R8 | KI-Texte sind als solche erkennbar (dezentes Symbol ✦). Eigene Texte nie. |

**Lernen & Planung**
| # | Regel |
|---|---|
| R9 | Jede Einheit zeigt vorher ihre **Dauer**. Pausieren jederzeit, Fortsetzen genau an der Stelle. |
| R10 | **Ein** Vorschlag statt einer Liste. Höchstens zwei Alternativen auf Wunsch. |
| R11 | **Keine roten Zahlen, keine Streaks, keine „verpasst"-Listen.** Fortschritt als Prognose. |
| R12 | Abends nur leichte Vorschläge. |
| R13 | Formulierungen sachlich und freundlich, nie vorwurfsvoll (siehe §7). |

**Allgemein**
| # | Regel |
|---|---|
| R14 | Offline ist ein Normalzustand, keine Fehlermeldung. |
| R15 | **Rückgängig überall:** 10-s-Toast nach jeder löschenden oder verändernden Massenaktion, `⌘Z` in Editoren, Papierkorb 30 Tage. |
| R16 | Leere Zustände erklären den nächsten Schritt in einem Satz und bieten genau eine Aktion an. |
| R17 | Reaktionszeit: Bedienung < 100 ms sichtbar, Bildschirmwechsel < 300 ms. Was länger dauert, zeigt einen ruhigen Platzhalter. |
| R18 | Bestätigungsdialoge nur für unumkehrbare Aktionen außerhalb des Papierkorbs (endgültig löschen, Wiederherstellung eines Backups). |

## 6. Zustände

| Zustand | Darstellung | Beispieltext |
|---|---|---|
| Leer | Satz + eine Aktion | „Noch keine Folien. Hier hineinziehen – oder ohne Folien starten." |
| Wird verarbeitet | ruhige Schrittliste | „Transkript ✓ · Folien zuordnen … · Konzepte –" |
| Offline (iPad ↔ Mac) | grauer Punkt + Kurztext an einer Stelle | „iPad nicht verbunden" |
| Cloud-KI nicht erreichbar | Hinweis an der betroffenen Funktion | „Wartet auf Internet – läuft automatisch weiter" |
| Modus „nur lokal" | Hinweis an der betroffenen Funktion | „Braucht Cloud-KI (in den Einstellungen aus)" |
| Fehler eines Jobs | an der Session, mit „erneut versuchen" | „Karten konnten nicht erstellt werden. Erneut versuchen" |
| Budget erreicht | einmal im Briefing | „KI-Budget für November erreicht. Videos pausieren bis 1.12." |

## 7. Texte & Ton

- **Du-Form**, kurze Sätze, aktive Verben. Buttons sind Verben: *Start*, *Los*, *Annehmen*, *Später*.
- **Keine Ausrufezeichen**, kein Druck, keine Superlative.
- Fachbegriffe in der Sprache des Moduls, beim ersten Auftreten zweisprachig.

| Statt | Besser |
|---|---|
| „Du hast 3 Lernblöcke verpasst!" | (nichts – still neu verteilt) |
| „Achtung: 147 Karten überfällig" | „Wiederholung · ≈ 20 min" |
| „Du bist schlecht in Normalisierung" | „Größter Hebel: *Normalisierung* · 15 min üben" |
| „Fehler: Keine Verbindung" | „iPad nicht verbunden" |
| „Super gemacht! 🔥 5 Tage in Folge!" | „18 Karten · 11 min. Am stärksten verbessert: *Normalisierung*." |

## 8. Visuelles System (Grundlagen)

| Element | Festlegung |
|---|---|
| Schrift | Mac: Systemschrift (SF Pro) bzw. Inter als Web-Fallback. iPad: SF Pro. Lernkarten 22–28 pt. |
| Raster | 4-pt-Grundraster, Abstände 4 · 8 · 12 · 16 · 24 · 32 |
| Farben | Neutrale Grautöne als Basis, **eine** Akzentfarbe für Hauptaktionen. **Rot nur** für den Aufnahmepunkt und endgültiges Löschen. |
| Modulfarben | Feste Palette mit 12 gedämpften Tönen, ausreichend Kontrast auf Hell und Dunkel |
| Beherrschung | Einfarbige Skala (hell → kräftig) mit Transparenz für Unsicherheit. Kein Ampelsystem. |
| Hell/Dunkel | Beide vollständig. In der Session standardmäßig dunkel. |
| Bewegung | Übergänge ≤ 150 ms, keine Effekte. Systemeinstellung „Bewegung reduzieren" wird beachtet. |
| Design-Tokens | In `packages/ui-tokens` als CSS-Variablen (Web) und Swift-Konstanten (iPad), aus einer gemeinsamen JSON-Quelle |

## 9. Barrierefreiheit

- Kontrast nach WCAG 2.1 AA (Text ≥ 4,5 : 1).
- Vollständig per Tastatur bedienbar (Mac), sichtbarer Fokus.
- VoiceOver-Beschriftungen für alle Bedienelemente (Web: ARIA, iPad: accessibilityLabel).
- Dynamische Schriftgrößen auf dem iPad (außer im Canvas).
- Informationen nie nur über Farbe (Beherrschung zusätzlich als Zahl, Marker mit Symbol).
